# Evaluation Methodology

## Method

Each case links an active requirement, an observed response, a user correction or evaluation, and a bounded technical analysis. Evidence IDs and chronology stay with the case. The analysis does not claim an internal cause unless the source proves it.

## Review History

The working layer includes corrective QC, independent QC, second corrective revision, independent re-validation, and targeted User Evaluation recovery. One historic QC root-cause uncertainty remains.
