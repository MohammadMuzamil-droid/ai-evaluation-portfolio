# CASE-008 — Repeated failure to preserve ARCHIVE command semantics

## What Happened

Three approved incident sequences show the ARCHIVE command being handled with changing meanings instead of one stable archive or listing operation.

## Why It Matters

A named workflow command becomes unreliable when its meaning changes across later uses and corrections.

## Why This Case Was Selected

It provides repeated, traceable observations across separate turns while keeping the three event groups inside one approved semantic incident.

## Evaluator Skill Demonstrated

Multi-turn context analysis, command-contract evaluation, consolidation, and uncertainty control.

## Distinct Value

The case tests continuity across time rather than a single response. It supports unstable command handling but does not identify a specific memory subsystem.
