## What Happened

The user presented a multipart JSON workflow question. The response moved into designing a new architecture instead of first resolving the operational question about the supplied structure.

## Why It Matters

Potentially useful design ideas still fail the task when they replace the requested field-level or workflow answer.

## Why This Case Was Selected

It has a clear difference between the active request and the type of task the response chose to perform.

## Evaluator Skill Demonstrated

Intent classification, structured-input analysis, instruction following, and workflow evaluation.

## Distinct Value

The case separates answer relevance from general usefulness. It does not claim that architecture discussion is always inappropriate.
