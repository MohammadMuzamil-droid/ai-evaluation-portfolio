# CASE-014 — Documentation workflow fidelity failure

## Why This Case Is Featured

The approved consolidation combines documentation-fidelity sequences in which approved text, source retrieval, and generated artefacts did not remain aligned. The evidence shows a workflow that should carry approved content forward and retrieve available project sources before asking the user to resubmit. It supports a fidelity/process finding, not a claim that every generated document was wholly unusable.

This case was selected for clear evidence, practical impact, and a distinct evaluation mechanism.
