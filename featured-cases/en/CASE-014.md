# CASE-014 — Documentation workflow fidelity failure

[Portfolio home](../../README.md) · [Featured cases](../../README.md#featured-cases) · [Full case](../../case-library/en/CASE-014.md) · [Bahasa Indonesia](../id/CASE-014.md)

## What Happened

Three approved sequences show gaps between approved text, available project sources, and generated artefacts. The workflow did not always carry the approved source forward or check available material before asking for it again.

## Why It Matters

Users can approve one version but receive, or be asked to recreate, another when source lineage breaks.

## Why This Case Was Selected

It links source retrieval, approval, generation, and output checking as one evidence-disciplined workflow.

## Evaluator Skill Demonstrated

Documentation-fidelity analysis, source hierarchy review, tool-use evaluation, and incident consolidation.

## Distinct Value

The case evaluates process integrity across stages. It does not claim that every generated document was wholly unusable.
