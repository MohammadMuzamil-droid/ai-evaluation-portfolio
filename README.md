# Evaluating ChatGPT Go in the Real World

*27 Evidence-Based Case Studies of Failures, Limitations, and Quality Issues*

**[Bahasa Indonesia](README-ID.md)**

## About This Portfolio

This portfolio reviews 27 cases from real-world use of ChatGPT Go. It uses verified case records, evidence mapping, human evaluation, and independent review.

## Executive Summary

The cases describe failures, limits, and quality issues in documented ChatGPT Go use. They are not claims about every ChatGPT plan, model, version, OpenAI product, or AI system.

- Cases: 27

## Methodology

The portfolio keeps evidence, conversation context, user evaluation, technical analysis, and final conclusions separate. It uses primary conversation records for traceability. Human decisions guide evaluation but are not presented as primary archive facts.

## Scope and Limitations

The cases come from ChatGPT Go use in this documented environment. They may not apply to other plans, configurations, models, versions, features, or products. The historic cause of a false-zero QC result is plausible but not confirmed because the original script/log is unavailable.
